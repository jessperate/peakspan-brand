Typography

Three font families form a clear hierarchy: Montagu Slab for editorial weight, DM Sans for UI clarity, and Roboto Mono for data and labels.

Font Families

/* UI, body, buttons */
--font-sans: 'DM Sans', Arial, sans-serif;

/* Labels, tags, code, data */
--font-mono: 'Roboto Mono', 'Trebuchet MS', monospace;

Interaction Patterns

Consistent animation timing and hover behaviors across the brand system.

Navigation

/* Team photo scale */

transition: 0.7s ease;
